# 현장 상담 대기·호출 관제 시스템

법무법인 제이엘 분양전환 현장에서 은행별 상담 대기열을 운영하는 실시간 시스템입니다.

## 화면 주소

`https://bank-queue.onrender.com` 뒤에 아래 주소를 붙여 사용합니다.

| 역할 | 주소 |
| --- | --- |
| 전체 접속 포털 | `/hub.html` |
| 관리자·방송 콘솔 | `/admin.html` |
| 대형 전광판 | `/display.html` |
| 진행요원 패널 | `/operator.html` |
| 우리은행 팀장 | `/woori_leader.html` |
| 상담사 창구 | `/teller.html?bank=kb` (woori, shinhan, fubon) |
| 고객 발권 (QR) | `/kiosk.html?bank=kb` (woori, shinhan, fubon) |

`/kiosk.html` 과 `/index.html` 은 같은 고객 발권 화면입니다. 기존 QR 을 그대로 쓰면 됩니다.

## 현장 준비 순서

1. **관리자 콘솔** 을 열고 블루투스 스피커를 연결한 뒤 `스피커 방송 켜기` 를 누릅니다.
   - 이 버튼을 눌러야 전 은행 호출 방송이 나갑니다.
   - 무음 신호를 계속 흘려보내 블루투스 스피커가 절전으로 들어가 첫 음절이 잘리는 것을 막습니다.
2. **표준 상담 시간** 을 현장에 맞게 조절합니다. 고객 예상 대기시간과 창구 지연 경고의 기준이 됩니다.
3. **은행별 창구 수** 를 `+ / -` 로 맞춥니다. 상담사 앱에 즉시 반영됩니다.
4. **대형 전광판** 을 열고 `전광판 음성 켜기` 를 누릅니다.
5. **상담사 창구** 앱을 각 은행 단말기에서 열고 창구를 한 번 선택합니다.
   - 선택한 창구는 새로고침해도 유지됩니다.
   - 자리를 옮길 때는 상단 `창구 이동` 버튼을 씁니다.
6. **고객 QR** 은 은행별 발권 주소로 만듭니다. 포털 화면에서 주소를 복사할 수 있습니다.

## 상담사 창구 앱

- **다음 고객 호출**: 대기열 맨 앞 고객을 부릅니다. 고객 휴대폰에 알림음·진동·전체화면 안내가 뜹니다.
- **재호출**: 같은 고객을 다시 부릅니다.
- **상담 완료 + 다음 호출**: 완료 처리 후 다음 고객을 자동으로 부릅니다.
- **부재 패스**: 불렀는데 오지 않은 고객을 대기열에서 내립니다. 고객 화면에는 다시 받기 버튼이 뜹니다.
- **대리 발권**: 어르신 대신 번호표를 뽑아 드립니다.
- 자기 은행에 새 고객이 접수되면 차임벨과 음성으로 알려줍니다. 다른 은행 접수는 울리지 않습니다.

## 고객 화면

- QR 을 찍으면 자동으로 번호표가 발급됩니다.
- `호출 알림 켜기` 를 눌러야 화면을 꺼둔 상태에서도 알림음이 울립니다.
- 내 앞 대기 인원과 예상 대기시간이 실시간으로 표시됩니다.
- 상담이 끝나면 다른 기관을 고르는 화면이 자동으로 나옵니다.

## 보고

관리자 콘솔 하단 `상담 실적 보고` 에서:

- **중간 현황 보기**: 언제든 현재까지의 실적을 봅니다.
- **일마감 및 일일보고**: 대기열과 창구를 비우고 일일보고를 만듭니다. 실적 통계는 남습니다.
- **보고 문자 복사**: 카카오톡이나 문자로 바로 보낼 요약본을 복사합니다.
- **엑셀(CSV) 저장**: 고객별 발권·호출·완료 시각과 대기·상담 소요시간을 내려받습니다.

집계 항목은 기관별·창구별 건수, 평균 상담시간, 평균 대기시간, 부재 패스 건수, 시간대별 분포입니다.
시간대는 서버 위치와 무관하게 항상 한국시간 기준으로 계산합니다.

## 비상 조치

| 상황 | 조치 |
| --- | --- |
| 번호가 꼬였다 | 관리자 콘솔 `전체 번호표 리셋` |
| 화면이 이상하다 | 관리자 콘솔 `비상 시스템 원클릭 복구` (창구 구성과 대기열이 초기화됩니다) |
| 소리가 안 난다 | 관리자 콘솔에서 `소리 시험`, 그래도 안 되면 스피커 버튼을 다시 누릅니다 |
| 고객이 못 들었다 | 관리자 콘솔 `직전 호출 재방송`, 또는 상담사 앱 `재호출` |

## 실행

```
npm install
npm start
```

기본 포트는 3000이며 `PORT` 환경변수로 바꿀 수 있습니다.
`SELF_URL` 은 슬립 방지 자기 호출 주소입니다. Render 배포 주소가 바뀌면 이 값을 맞춰주세요.
