# 현장 상담 대기·호출 관제 시스템

> **현재 운영 종료(전체 차단)** — 2026-10-18 전주 행사 종료 후, 링크 유출로 인한 프로그램 유포를 막기 위해 모든 화면·파일·실시간 연결을 막아 두었습니다(`/healthz` 만 응답).
> 다시 열기: 대표님 지시 → `server.js` 의 `SITE_CLOSED` 를 `false` 로 바꿔 배포. 비상시 Render 환경변수 `SITE_OPEN=1` 로도 열 수 있습니다.

법무법인 제이엘 분양전환 현장(전주)에서 **법무법인 제이엘 상담을 먼저 받고, 그다음 은행 상담**으로 이어지는 대기열을 운영하는 실시간 시스템입니다.

상담처: 법무법인 제이엘(jl) · NH농협은행(nh) · 신한은행(shinhan) · 국민은행(kb) · 푸본현대생명(fubon)

## 운영 방식 2가지 (링크·QR 은 같음)

관리자 화면 맨 위 **🏢 운영 방식** 버튼으로 바꿉니다. 바꾸면 모든 화면이 바로 그 방식으로 동작하고, 재시작·재배포 뒤에도 유지됩니다(관리자 화면을 한 번 열면 자동으로 다시 적용).

| 방식 | 손님 | 번호 | 언제 |
| --- | --- | --- | --- |
| **🎫 일반 단지(선착순)** — 기본 | QR 을 찍으면 바로 번호표 | 온 순서대로 1, 2, 3… | 예약 없이 운영하는 단지 |
| **📋 사전예약 단지** | QR 후 동·호수 입력 → 예약 시간이면 예약 번호, 아니면 현장 접수 | 예약 1, 2, 3… / 현장 접수 1001~(주황) · 예약 우선 호출 | 시간대별 사전예약 단지(전주 방식) |

- 두 방식 모두 **법무법인 제이엘 상담 먼저 → 은행** 순서입니다.
- 사전예약 단지는 관리자 화면 '예약자 명단' 카드에서 그 단지 예약 엑셀을 올려야 예약 확인이 시작됩니다. 예전 단지 명단이 남아 있으면 바꿀 때 경고가 뜨니 [명단 지우기] 후 새 명단을 올리세요.
- 명단을 서버에 고정해 두려면(재배포해도 유지) 암호화한 명단을 `data/reserve_seed.enc` 로 넣고 Render 환경변수 `RESERVE_KEY` 를 지정합니다. 전주 명단은 행사 종료 후 삭제했습니다.
- Render 환경변수 `SITE_MODE=reserve` 를 주면 기본 방식이 사전예약이 됩니다(지정하지 않으면 일반).

## 화면 주소

`https://bank-queue.onrender.com` 뒤에 아래 주소를 붙여 사용합니다.

| 역할 | 주소 |
| --- | --- |
| 전체 접속 포털 | `/hub.html` |
| 관리자·방송 콘솔 | `/admin.html` |
| 대형 전광판 | `/display.html` |
| 진행요원 패널 | `/operator.html` |
| 상담사 창구 | `/teller.html?b=jl&desk=1` (nh, shinhan, kb, fubon / desk 를 붙이면 그 창구로 바로 열림) |
| 예약자 확인 · 현장안내 (대리발권) | `/reserve.html` |
| 고객 발권 (QR) | `/index.html?b=jl` 또는 `/kiosk.html?b=jl` |

`?b=` 와 `?bank=` 를 모두 받습니다. `/kiosk.html` 과 `/index.html` 은 같은 고객 발권 화면입니다.

## 제이엘 우선 흐름

1. 손님이 **어느 QR 을 찍든** 법무법인 제이엘 번호표가 먼저 나옵니다.
   은행 QR 을 먼저 찍은 손님은 제이엘 화면으로 넘어가고, "분양전환 상담(법무법인 제이엘)을 먼저 받으신 뒤 ○○ 상담을 받으실 수 있습니다" 라는 안내가 뜹니다.
2. 제이엘 상담이 끝나면 손님 화면에 **은행 선택 화면**이 나옵니다. 은행을 누르면 그 은행 번호표가 나옵니다.
   제이엘 대기 중에 은행 QR 을 미리 찍어둔 손님은, 제이엘 상담이 끝나는 순간 그 은행 번호표가 자동으로 나옵니다.
3. **제이엘에서 상담 중인 손님은 은행이 부를 수 없습니다.**
   은행 상담사 앱 대기 목록에 `○번 · 제이엘 상담중` 으로 표시되고, 다음 호출에서 자동으로 건너뜁니다.
4. 한 손님이 한 번에 한 기관의 번호표만 가질 수 있습니다. 상담이 끝나야 다음 기관 번호표가 나옵니다.
5. 제이엘 완료는 **그날만** 인정합니다. 다음 날 다시 오시면 제이엘부터 시작합니다.

**예외는 직원 대리발권뿐입니다.** 제이엘 상담이 필요 없는 손님(다른 날 받으셨거나, 폰을 바꾸셨거나)은
관리자 콘솔이나 진행요원 패널의 `대리 발권` 으로 바로 은행 번호표를 드리세요. 대리발권은 순서 검사를 하지 않습니다.

손님은 같은 폰, 같은 브라우저로 계속 들어오셔야 합니다. 카카오톡 안의 브라우저로 열었다가 크롬으로 다시 열면 다른 폰으로 봅니다.

## 시간예약자 우선 (예약자 확인)

시간대마다 예약 인원이 정해져 있어 예약자가 우선이다. 관리자 콘솔 '예약자 명단' 카드에서 예약 엑셀(동·호수·연락처·신청 시간)을 올리면 켜진다.

- 손님이 제이엘 QR 을 찍으면 동·호수를 입력한다. 지금이 그 세대의 예약 시간대면 바로 번호표가 나오고, 예약자 확인 화면에 'QR 자동 확인'이 찍힌다.
- 인정 시간(관리자 콘솔 '예약 인정 시간'에서 바꿈, 즉시 전체 반영): 기본은 각 타임 정시 10분 전 ~ 다음 타임 정시(예: 1시 예약 → 12:50~14:00). 그날 첫 타임은 30분 전부터, 마지막 타임은 끝나고 30분까지.
- 예약이 없거나 시간이 다르면 "시간예약자 우선입니다" 안내와 함께 **현장 접수** 버튼이 나온다(누르면 바로 번호표, 시간 제한 없음).
- **현장 접수 번호는 1001번부터**(예약 고객은 1, 2, 3…) 따로 매기고, 손님 폰·전광판·상담사 앱·대리발권 결과에서 **주황색**으로 표시한다. 손님 폰의 대기 인원도 예약/현장을 따로 세고, 현장 접수는 예상 시간 대신 '예약 우선'으로 안내한다.
- 제이엘 '다음 호출'은 기다리는 예약 고객을 먼저 부른다. 상담사는 '현장 접수 고객 호출' 버튼이나 번호를 눌러 상황에 따라 현장 손님을 부른다. 방송도 "예약 고객 N번 / 현장 접수 고객 N번"으로 구분한다.
- 은행은 제이엘 상담을 마친 손님만 받으므로 예약/현장 구분이 없다.
- 예약자 확인 화면(`/reserve.html`)은 여러 명이 동시에 쓰고, 한 명이 표시하면 모두의 화면에 바로 뜬다. '엑셀로 받기'로 도착 현황을 내려받는다(명단을 올린 PC 에서는 원본 연락처 포함).
- 연락처는 가운데 4자리를 가린 채로만 서버에 올라간다. 서버가 재시작돼도 예약자 화면을 연 폰들의 저장본으로 자동 복구된다.
- 문제가 생기면 관리자 콘솔에서 '예약 확인 끄기'를 누르면 누구나 QR 로 바로 번호표를 받는다.

## 앱으로 설치하기

링크를 매번 여는 대신 홈 화면에 앱으로 설치할 수 있습니다. 링크 방식도 그대로 됩니다.

- **안드로이드(갤럭시 등)**: 크롬이나 삼성인터넷으로 열면 왼쪽 아래에 `📲 앱으로 설치` 버튼이 뜹니다. 누르면 바로 설치됩니다.
- **아이폰·아이패드**: 사파리로 열고 아래 공유 버튼 → `홈 화면에 추가` 를 누릅니다. 화면의 설치 버튼을 누르면 안내가 나옵니다.
- **PC (윈도우·맥, 크롬·엣지)**: 같은 설치 버튼이 뜹니다. 설치하면 주소창 없는 창 앱으로 열립니다.
  전광판과 관리자 콘솔은 PC 에 설치해두는 편이 안정적입니다.
- **맥 사파리**: 공유 메뉴의 `Dock에 추가` 를 씁니다. 설치 버튼을 누르면 안내가 나옵니다.

### 카카오톡으로 링크를 보낼 때 주의

카톡으로 받은 링크를 그냥 누르면 카톡 안에 있는 브라우저로 열립니다.
여기서는 앱 설치가 안 되고 **호출 음성과 알림음도 나오지 않을 수 있습니다.**

이 상태를 감지하면 화면 아래에 빨간 경고가 뜹니다.
안드로이드는 경고의 `크롬으로 열기` 를 누르면 되고, 아이폰은 공유 버튼에서 `Safari로 열기` 를 누릅니다.

설치된 앱은 역할과 기관에 맞는 이름과 아이콘을 갖습니다.
예를 들어 농협 창구 단말기는 `NH농협은행 창구 상담사` 라는 이름과 농협 색 아이콘으로 설치됩니다.
상담사에게는 `/teller.html?b=nh` 처럼 자기 기관 주소를 한 번만 보내주고 설치하게 하면 됩니다.

## 현장 준비 순서

1. **관리자 콘솔** 을 열고 블루투스 스피커를 연결한 뒤 `스피커 방송 켜기` 를 누릅니다.
   - 이 버튼을 눌러야 호출 방송이 나갑니다.
   - **관리자 콘솔 창은 하루 종일 켜두세요.** 서버가 재시작돼도 이 창이 대기 손님·번호·실적을 자동으로 되살립니다.
   - 앰프 줄의 `화면 항상 켜기` 가 **작동 중**, `서버 연결` 이 **정상** 인지 확인하세요.
2. **당일 상담 운영시간** 을 오늘 일정에 맞게 정합니다. 시간대별 상담 실적이 이 구간으로 정리됩니다.
   `호출 방송 반복 횟수` 는 기본 1회입니다.
3. **기관별 창구 수** 를 `+ / -` 로 맞춥니다. 기본은 제이엘 5, 농협 2, 신한 3, 국민 2, 푸본 1 입니다.
4. **대형 전광판** 을 열고 `전광판 음성 켜기` 를 누릅니다.
   관리자 스피커와 전광판이 같은 공간에 있으면 소리가 두 번 들리므로 한쪽만 켜세요.
5. **상담사 창구** 앱을 각 기관 단말기에서 열고 담당 창구를 고릅니다.
   - 창구는 기억하지 않습니다. 새로고침하면 다시 고릅니다.
   - 자리를 옮길 때는 상단 `창구 이동` 버튼을 씁니다.
6. **고객 QR**: 흐름상 **제이엘 QR(`/index.html?b=jl`) 하나면 충분**합니다. 은행 QR 을 붙여도 제이엘로 안내되니 문제없습니다.

## 상담사 창구 앱

- **다음 고객 호출**: 대기열 맨 앞 고객을 부릅니다. 제이엘 상담 중인 손님은 건너뜁니다.
- **재호출**: 같은 고객을 다시 부릅니다.
- **상담 완료**: 완료 처리만 합니다. 다음 손님은 준비되면 **다음 고객 호출**로 부릅니다(쉬거나 다른 일을 할 때 저절로 호출되지 않음).
- 상담 중에 **다음 고객 호출**(또는 현장 접수 호출·번호 지정 호출)을 누르면 지금 손님은 **자동으로 상담 완료** 처리됩니다(버튼에 '완료하고 …'로 표시). 손님 폰에는 바로 은행 선택이 뜹니다.
- **부재 패스**: 불렀는데 오지 않은 고객을 대기열에서 내립니다. 고객 화면에는 다시 받기 버튼이 뜹니다.
- **창구 전달**: 지금 상담 중인 손님을 비어 있는 옆 창구로 넘깁니다.
- **실수 취소**: 상담 완료를 잘못 눌렀을 때 직전 손님을 다시 불러옵니다. 완료 후 5분 안에만 됩니다.
  제이엘에서 되돌리려는 손님이 이미 은행 창구에서 상담 중이면 되돌릴 수 없습니다.
- **자리 비움**: 잠깐 자리를 뜰 때 누릅니다. 비운 창구는 예상 대기시간 계산에서 빠집니다.
- **대기열 번호를 눌러 지정 호출**: 맨 앞이 아닌 특정 손님을 바로 부를 수 있습니다.
- **부재 처리한 손님 되돌리기**: 부재 처리한 분이 다시 오시면 번호를 눌러 대기열 맨 앞으로 되살립니다.
- 호출 버튼은 빠르게 두 번 눌러도 한 번만 처리됩니다.
- 상담사 앱은 음성을 내지 않습니다. 새 고객 접수와 내 창구 호출은 차임벨로만 알려줍니다.

대리 발권은 상담사 앱에 없습니다. 관리자 콘솔과 진행요원 패널에서 합니다.

## 호출 방송

- 관리자 스피커와 전광판이 방송합니다. 손님 폰에도 알림음·진동·전체화면 안내가 뜹니다.
- 같은 호출은 한 번만 방송됩니다. 버튼을 연타하거나 신호가 겹쳐도 중복되지 않습니다.
- 여러 창구가 동시에 부르면 앞 방송이 끝난 뒤 순서대로 나갑니다. 중간에 끊기지 않습니다.
- 반복 횟수는 관리자 콘솔에서 1~3회로 정합니다(기본 1회).

## 고객 화면

- QR 을 찍으면 자동으로 번호표가 발급됩니다(제이엘 먼저).
- `호출 알림 켜기` 를 눌러야 화면을 꺼둔 상태에서도 알림음이 울립니다.
- 내 앞 대기 인원과 예상 대기시간이 실시간으로 표시됩니다.
- 화면이 꺼져 있는 동안 상담이 끝났거나 호출됐어도, 다시 켜면 정확한 상태가 나옵니다. 새 번호가 저절로 나오지 않습니다.

| 관리자 콘솔 | 전 기관 (설정 변경과 대리 발권 가능) |
| 진행요원 패널 | 전 기관 (대리 발권 가능) |
| 대형 전광판 | 전 기관, `?b=` 를 붙이면 해당 기관만 |
| 상담사 창구 | 자기 기관, 자기 창구만 |

당일 운영시간과 예상 상담 소요시간은 관리자 콘솔에서만 바꿀 수 있고, 바꾸는 즉시 전 화면에 반영됩니다.

## 보고

관리자 콘솔 하단 `상담 실적 보고` 에서:

- **중간 현황 보기**: 언제든 현재까지의 실적을 봅니다.
- **일마감 및 일일보고**: 대기열과 창구를 비우고 번호를 1번부터 다시 시작합니다. 완료 실적 통계는 남습니다.
- **보고 문자 복사**: 카카오톡이나 문자로 바로 보낼 요약본을 복사합니다.
- **엑셀(CSV) 저장**: 고객별 발권·호출·완료 시각과 대기·상담 소요시간을 내려받습니다.

시간은 서버 위치와 무관하게 항상 한국시간 기준으로 계산합니다.

## 비상 조치

| 상황 | 조치 |
| --- | --- |
| 화면이 멈춘 것 같다 | 먼저 그 화면을 **새로고침(F5)** 합니다. 대부분 이것으로 해결됩니다 |
| 창구 상태가 꼬였다 | 관리자 콘솔 `비상 시스템 원클릭 복구`. **대기 손님과 실적은 지워지지 않습니다.** 멈춘 창구 표시와 방송만 정리하고, 상담 중이던 손님은 대기 맨 앞으로 돌아갑니다 |
| 테스트를 마치고 처음부터 시작 / 번호를 처음부터 다시 | 관리자 콘솔 `전체 번호표 리셋`. **대기 손님과 오늘 누적 실적(완료 기록)이 모두 지워지고**, 리셋 전 테스트 폰의 '제이엘 완료'도 무효가 됩니다. 이어지는 두 번째 확인에서 예약자 확인 표시도 지울 수 있습니다(명단은 유지) |
| 은행이 손님을 못 부른다 | 그 손님이 제이엘 상담 중입니다. 제이엘 상담이 끝나면 부를 수 있습니다 |
| 제이엘 없이 은행만 보실 손님 | 관리자 콘솔이나 진행요원 패널 `대리 발권` |
| 손님이 "번호가 초기화됐다"는 화면을 본다 | 번호표 리셋이나 일마감 뒤입니다. 손님이 `번호표 다시 받기` 를 누르면 됩니다 |
| 소리가 안 난다 | 관리자 콘솔에서 `소리 시험`, 그래도 안 되면 스피커 버튼을 다시 누릅니다 |
| 상담 완료를 잘못 눌렀다 | 상담사 앱 `실수 취소` (5분 이내) |
| 부재 처리한 분이 다시 왔다 | 상담사 앱 아래 `부재 처리한 손님` 에서 번호를 누릅니다 |
| 고객이 못 들었다 | 관리자 콘솔 `직전 호출 재방송`, 또는 상담사 앱 `재호출` |

## 실행

```
npm install
npm start
```

기본 포트는 3000이며 `PORT` 환경변수로 바꿀 수 있습니다.
`SELF_URL` 은 슬립 방지 자기 호출 주소입니다. Render 배포 주소가 바뀌면 이 값을 맞춰주세요.
`DATA_DIR` 을 영구 디스크 경로로 지정하면 재배포해도 저장 파일이 남습니다.
