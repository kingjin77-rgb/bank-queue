# 현장 상담 대기·호출 관제 시스템

법무법인 제이엘 분양전환 현장에서 은행별 상담 대기열을 운영하는 실시간 시스템입니다.

## 화면 주소

`https://bank-queue.onrender.com` 뒤에 아래 주소를 붙여 사용합니다.

| 역할 | 주소 |
| --- | --- |
| 전체 접속 포털 | `/hub.html` |
| 관리자·방송 콘솔 | `/admin.html` |
| 대형 전광판 | `/display.html` |
| 진행요원 패널 | `/operator.html` |
| 우리은행 팀장 | `/woori_leader.html` |
| 상담사 창구 | `/teller.html?b=kb` (woori, shinhan, fubon) |
| 고객 발권 (QR) | `/kiosk.html?b=kb` 또는 `/index.html?b=kb` |

`?b=` 와 `?bank=` 를 모두 받습니다. 이미 배포한 QR, NFC, 링크를 그대로 쓰시면 됩니다.
`/kiosk.html` 과 `/index.html` 은 같은 고객 발권 화면입니다.

## 앱으로 설치하기

링크를 매번 여는 대신 홈 화면에 앱으로 설치할 수 있습니다. 링크 방식도 그대로 됩니다.

- **안드로이드(갤럭시 등)**: 크롬이나 삼성인터넷으로 열면 왼쪽 아래에 `📲 앱으로 설치` 버튼이 뜹니다. 누르면 바로 설치됩니다.
- **아이폰·아이패드**: 사파리로 열고 아래 공유 버튼 → `홈 화면에 추가` 를 누릅니다. 화면의 설치 버튼을 누르면 안내가 나옵니다.
- **PC (윈도우·맥, 크롬·엣지)**: 같은 설치 버튼이 뜹니다. 설치하면 주소창 없는 창 앱으로 열립니다.
  전광판과 관리자 콘솔은 PC 에 설치해두는 편이 안정적입니다.
- **맥 사파리**: 공유 메뉴의 `Dock에 추가` 를 씁니다. 설치 버튼을 누르면 안내가 나옵니다.

### 카카오톡으로 링크를 보낼 때 주의

카톡으로 받은 링크를 그냥 누르면 카톡 안에 있는 브라우저로 열립니다.
여기서는 앱 설치가 안 되고 **호출 음성과 알림음도 나오지 않을 수 있습니다.**

이 상태를 감지하면 화면 아래에 빨간 경고가 뜹니다.
안드로이드는 경고의 `크롬으로 열기` 를 누르면 되고, 아이폰은 공유 버튼에서 `Safari로 열기` 를 누릅니다.
한 번 제대로 열어 앱으로 설치해두면 다음부터는 앱 아이콘으로 들어가므로 문제가 없습니다.

설치된 앱은 역할과 은행에 맞는 이름과 아이콘을 갖습니다.
예를 들어 우리은행 창구 단말기는 `우리은행 창구 상담사` 라는 이름과 우리은행 색 아이콘으로 설치됩니다.
상담사에게는 `/teller.html?b=우리은행코드` 주소를 한 번만 보내주고 설치하게 하면 됩니다.

## 현장 준비 순서

1. **관리자 콘솔** 을 열고 블루투스 스피커를 연결한 뒤 `스피커 방송 켜기` 를 누릅니다.
   - 이 버튼을 눌러야 전 은행 호출 방송이 나갑니다.
   - 무음 신호를 계속 흘려보내 블루투스 스피커가 절전으로 들어가 첫 음절이 잘리는 것을 막습니다.
   - 앰프 줄의 `화면 항상 켜기` 가 **작동 중**, `서버 연결` 이 **정상** 인지 확인하세요.
     화면이 꺼지면 브라우저가 음성 합성을 멈춰 방송이 안 나갑니다. 이 표시가 그것을 막아줍니다.
   - 음성이 나가지 않는 상태가 감지되면 앰프 박스에 빨간 경고가 뜹니다.
2. **당일 상담 운영시간** 을 오늘 일정에 맞게 정합니다. 예를 들어 16시부터 20시까지 상담한다면
   시작 16시, 종료 20시로 맞춥니다. 시간대별 상담 실적이 이 구간으로 정리됩니다.
   자주 쓰는 시간대는 프리셋 버튼으로 한 번에 고를 수 있습니다.
   그 아래 `1인당 예상 상담 소요시간` 은 고객 화면의 예상 대기시간 계산에만 쓰입니다.
3. **은행별 창구 수** 를 `+ / -` 로 맞춥니다. 상담사 앱에 즉시 반영됩니다.
4. **대형 전광판** 을 열고 `전광판 음성 켜기` 를 누릅니다.
5. **상담사 창구** 앱을 각 은행 단말기에서 열고 창구를 한 번 선택합니다.
   - 선택한 창구는 새로고침해도 유지됩니다.
   - 자리를 옮길 때는 상단 `창구 이동` 버튼을 씁니다.
6. **고객 QR** 은 은행별 발권 주소로 만듭니다. 포털 화면에서 주소를 복사할 수 있습니다.

## 상담사 창구 앱

- **다음 고객 호출**: 대기열 맨 앞 고객을 부릅니다. 고객 휴대폰에 알림음·진동·전체화면 안내가 뜹니다.
- **재호출**: 같은 고객을 다시 부릅니다.
- **상담 완료 + 다음 호출**: 완료 처리 후 다음 고객을 자동으로 부릅니다.
- **부재 패스**: 불렀는데 오지 않은 고객을 대기열에서 내립니다. 고객 화면에는 다시 받기 버튼이 뜹니다.
- **창구 전달**: 지금 상담 중인 손님을 옆 창구로 넘깁니다.
- **실수 취소**: 상담 완료를 잘못 눌렀을 때 직전 손님을 다시 불러옵니다. 완료 후 5분 안에만 됩니다.
  자동으로 다음 손님을 부른 상태여도 그 손님을 대기열 맨 앞으로 되돌리고 이전 손님을 복구합니다.
- **자리 비움**: 잠깐 자리를 뜰 때 누릅니다. 비운 창구는 예상 대기시간 계산에서 빠지고,
  전광판과 관제 화면에도 표시됩니다. 호출을 누르면 자동으로 복귀합니다. 상담 중에는 비울 수 없습니다.
- **대기열 번호를 눌러 지정 호출**: 맨 앞이 아닌 특정 손님을 바로 부를 수 있습니다.
- **부재 처리한 손님 되돌리기**: 부재 처리한 분이 다시 오시면 번호를 눌러 대기열 맨 앞으로 되살립니다.
- 자기 은행에 새 고객이 접수되면 차임벨과 음성으로 알려줍니다. 다른 은행 접수는 울리지 않습니다.
- **창구 이동**: 상단 버튼으로 본인이 다른 자리로 옮깁니다. 창구 전달과는 다른 기능입니다.

대리 발권은 상담사 앱에 없습니다. 관리자 콘솔과 진행요원 패널에서 합니다.

## 고객 화면

- QR 을 찍으면 자동으로 번호표가 발급됩니다.
- `호출 알림 켜기` 를 눌러야 화면을 꺼둔 상태에서도 알림음이 울립니다.
- 내 앞 대기 인원과 예상 대기시간이 실시간으로 표시됩니다.
- 상담이 끝나면 다른 기관을 고르는 화면이 자동으로 나옵니다.

## 화면별 권한 범위

| 화면 | 볼 수 있는 범위 |
| --- | --- |
| 관리자 콘솔 | 전 기관 (설정 변경과 대리 발권 가능) |
| 진행요원 패널 | 전 기관 (대리 발권 가능) |
| 대형 전광판 | 전 기관, `?b=` 를 붙이면 해당 기관만 |
| 우리은행 팀장 | 우리은행만 |
| 상담사 창구 | 자기 은행, 자기 창구만 |

당일 운영시간과 예상 상담 소요시간은 관리자 콘솔에서만 바꿀 수 있고, 바꾸는 즉시 전 화면에 반영됩니다.

## 보고

관리자 콘솔 하단 `상담 실적 보고` 에서:

- **중간 현황 보기**: 언제든 현재까지의 실적을 봅니다.
- **일마감 및 일일보고**: 대기열과 창구를 비우고 일일보고를 만듭니다. 실적 통계는 남습니다.
- **보고 문자 복사**: 카카오톡이나 문자로 바로 보낼 요약본을 복사합니다.
- **엑셀(CSV) 저장**: 고객별 발권·호출·완료 시각과 대기·상담 소요시간을 내려받습니다.

집계 항목은 기관별·창구별 건수, 평균 상담시간, 평균 대기시간, 부재 패스 건수, 시간대별 분포입니다.
시간대별 표는 관리자 콘솔에서 정한 당일 운영시간 구간으로 만들어집니다.
운영시간 밖에 완료된 상담이 있으면 그 시간대도 표에 함께 나옵니다.
시간은 서버 위치와 무관하게 항상 한국시간 기준으로 계산합니다.

## 비상 조치

| 상황 | 조치 |
| --- | --- |
| 번호가 꼬였다 | 관리자 콘솔 `전체 번호표 리셋` |
| 화면이 이상하다 | 관리자 콘솔 `비상 시스템 원클릭 복구` (창구 구성과 대기열이 초기화됩니다) |
| 소리가 안 난다 | 관리자 콘솔에서 `소리 시험`, 그래도 안 되면 스피커 버튼을 다시 누릅니다 |
| 상담 완료를 잘못 눌렀다 | 상담사 앱 `실수 취소` (5분 이내) |
| 부재 처리한 분이 다시 왔다 | 상담사 앱 아래 `부재 처리한 손님` 에서 번호를 누릅니다 |
| 관리자 화면이 꺼져 방송이 끊긴다 | `화면 항상 켜기` 표시를 확인하고, 노트북 절전 설정도 해제하세요 |
| 상담사 앱에 음성이 없다 | 화면 위 노란 안내줄을 누르면 음성이 켜집니다 |
| 창구가 잘못 잡혔다 | 상담사 앱 상단 `창구 이동` 을 누릅니다 |
| 고객이 못 들었다 | 관리자 콘솔 `직전 호출 재방송`, 또는 상담사 앱 `재호출` |

## 실행

```
npm install
npm start
```

기본 포트는 3000이며 `PORT` 환경변수로 바꿀 수 있습니다.
`SELF_URL` 은 슬립 방지 자기 호출 주소입니다. Render 배포 주소가 바뀌면 이 값을 맞춰주세요.
